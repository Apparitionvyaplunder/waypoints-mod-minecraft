## 📖 About

Waypoints Mod lets you save named locations across all three dimensions, displaying them as in-world beams and HUD markers with distance and dimension labels.

---

## ✨ Features
<a name="features"></a>

- **Unlimited Waypoints** — save as many as needed.
- **Dimension Support** — separate Overworld, Nether, and End lists.
- **In-World Beams** — coloured column beams at each waypoint.
- **HUD Markers** — distance and label shown on screen.
- **Death Waypoint** — automatically saves on every death.
- **Import/Export** — share waypoint lists as JSON.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
